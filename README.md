# Dreamcustomboxes
An interactive custom packaging design studio for creating, customizing, previewing, and exporting box designs in 2D and 3D.
**Dreamcustomboxes – Online Custom Packaging Design Studio**

Dreamcustomboxes is an interactive packaging design studio that allows users to create, customize, and preview packaging designs in 2D and 3D. Customize box styles, dimensions, materials, colors, text, images, and finishes, then export your designs as SVG, PNG, or editable JSON files.

Built with React, TypeScript, Three.js, and Cloudflare Workers, the platform also supports online project management and secure artwork storage.
